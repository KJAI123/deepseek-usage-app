# DeepSeek 用量面板 — 使用指南

一个常驻菜单栏的悬浮窗小工具，实时显示你的 DeepSeek API 余额，附带用量看板与桌面小组件。

## 1. 获取 API Key（首次使用）

应用需要 DeepSeek **API Key** 才能读取账号余额。你的 Key 永远不会离开你的电脑。

1. 打开 <https://platform.deepseek.com> 并**注册 / 登录**（邮箱或手机号均可）。
2. 余额为 0 时先**充值**少量金额（API 按预付费计费；新账号平台会赠送少量额度）。
3. 进入 **API Keys → 创建新 API key**，命名（如 `floating-panel`），复制 `sk-…` 开头的字符串。
4. 启动应用——首次启动会自动弹出设置窗口。把 Key 粘贴到 **API Key** 输入框，点击**保存**。

> 设置窗口底部有一个蓝色链接 **「如何获取 API Key？」**，点击直接打开 DeepSeek 开放平台的 API Key 页面。

**提示**：余额是**账号级**而不是 Key 级的——同一账号下的任意 Key 查到的都是同一个总余额，所以可以创建多个 Key、粘贴任意一个即可。多账号场景用「当前账号」旁的 **+ / −** 按钮切换。

## 2. 悬浮窗

应用常驻**菜单栏（¥ 图标）**，点击图标显示/隐藏悬浮面板。

三种显示模式（设置 → 显示模式）：

| 模式 | 显示内容 |
|---|---|
| **极简** | 只显示总余额 |
| **标准** | 余额 + 赠送/充值明细 |
| **看板** | 卡片 + 迷你用量曲线 |

面板默认每 30 秒自动刷新。拖动标题栏可移动窗口；右上角 **Pin 按钮**（或设置 → 窗口置顶）可让面板始终位于所有窗口之上，取消后恢复普通窗口行为。

## 3. 用量看板

菜单 → **用量看板…**（或按 `⌘D`）打开完整看板：

- 六张核心卡片：**当前余额、今日消耗、累计消耗、累计充值、记录天数、区间最高**（另附**预估可用天数**）
- 余额走势 + 每日用量曲线（一天一格）
- 时间范围：**近 7 天 / 近 30 天 / 全部**
- **自定义**可勾选显示/隐藏卡片、切换图表模式（余额走势 / 每日用量 / 双轴对比）、隐藏曲线图、并可将看板窗口置顶——所有选项自动保存。

## 4. 设置项

| 标签页 | 可配置内容 |
|---|---|
| **基础** | 当前账号、API Key（可显示明文）、显示模式、数据源、网关地址、自动刷新间隔、API Key 指引 |
| **外观** | 主题色（8 种 Apple 风格配色）、面板透明度、浅色/深色/跟随系统、语言（中文 / English）、窗口置顶 |
| **看板** | 显示哪些卡片、默认时间范围、显示/隐藏曲线图、看板窗口置顶 |
| **提醒** | 余额低于阈值时系统通知、清除历史数据、导出历史 CSV |

## 5. 数据来源与口径

- **官方 API**：`GET https://api.deepseek.com/user/balance`（Bearer Key 鉴权）返回账号级余额，按设定间隔自动刷新。
- **自定义网关**：兼容 new-api / one-api 等 OpenAI 网关，自动探测 `{gateway}/user/balance` 与 `{gateway}/v1/user/balance`（兼容 DeepSeek 与 OpenAI 两种响应格式）。
- **用量曲线**：官方没有公开的按日用量接口（网页后台用的是内部 API），因此看板基于**本地记录的余额历史**推导——余额为折线，每日用量为相邻余额的差值（下降=消耗，上升=充值/赠送）。

## 6. 数据与隐私

- 数据保存在 `~/Library/Application Support/DeepSeekUsagePanel/`（macOS）或 `%APPDATA%/deepseek-usage-app/`（Windows）；API Key 同时写入 macOS 钥匙串兜底。
- 应用**不收集、不上传任何数据**——所有请求只发往你配置的 DeepSeek 官方地址或你自己的网关。

## 7. 常见问题

| 问题 | 解决 |
|---|---|
| 面板显示「未设置 Key」 | 打开设置，粘贴 `sk-…` 密钥并保存 |
| 「Key 无效或已过期」 | 到开放平台重新创建密钥，检查粘贴时是否混入空格 |
| 余额一直为 0 | 先在开放平台充值 |
| 自定义网关不生效 | 确认地址指向 new-api/one-api 风格的网关，可带 `/v1` 后缀 |
| 小组件无内容（macOS 14+） | 右键桌面 → 编辑小组件 → 添加 **DeepSeek**，每 15 分钟刷新一次 |
